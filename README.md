# Nika для Android — BeeWare (Toga + Briefcase)

Голосовой ассистент в телефоне: **позвони маме**, **открой ютуб**, **засеки 10 минут**,
**какой пароль от вайфая**, **погода** — и просто живой разговор.
Палитра и характер перенесены из Windows-версии: тёмный фон `#0d0d0f`,
бордовый `#c81e3a`, приглушённый `#7a4a52`.

![Макет интерфейса Nika на Toga](docs/preview.png)

> Это макет один в один по раскладке `nika/app.py`: Toga не умеет отдавать
> скриншот виджета, как Kivy, поэтому макет нарисован тем же кодом цветов.
> Подписи «рядом» в левом верхнем углу больше нет — только имя и кнопки.

---

## Что изменилось после Kivy

- **Kivy заменён на BeeWare**: интерфейс — нативные виджеты `toga` (Box, Label,
  Button, TextInput, ScrollContainer), сборка — `briefcase`, Android-мост — Chaquopy.
- **«рядом» убрано** из шапки. Статус («ищу контакты…», «печатает…») теперь
  показывается строкой в ленте сообщений, а не подписью под именем.
- **Все функции сохранены**: звонки, смс, приложения и сайты, таймер, будильник,
  напоминания, фонарик, заряд, звук, погода, поиск, заметки, память, голос,
  обучение фразам.
- Сборка переехала на **Briefcase + GitHub Actions**: тесты → APK в артефактах.

Плата за нативность: у Toga нет скруглённых «пузырей» и произвольной отрисовки,
поэтому сообщения — полосы на всю ширину с фирменными цветами и выравниванием
(слева — Nika, справа — ты). Кнопки системные, но покрашены в те же цвета.

## Что умеет

### Телефон

| Скажи | Что будет |
|---|---|
| `позвони маме` | находит контакт (падежи: «маме/мама/маму»), при двух номерах переспрашивает |
| `позвони 89601234567` | нормализует номер в `+7 960 123-45-67` |
| `позвони в скорую` | 103 (полиция 102, пожарные 101, МЧС 112) |
| `звони сразу` / `показывай номер` | звонить без лишнего нажатия или только открывать номер |
| `напиши смс маме я скоро буду` | открывает сообщение с готовым текстом |
| `открой ютуб`, `открой телеграм` | запускает приложение, если стоит |
| `открой госуслуги` | нет приложения — откроет сайт; нет и сайта — Play Market |
| `открой youtube.com` | открывает ссылку в браузере |
| `засеки 10 минут`, `таймер на полчаса` | таймер с полосой сверху |
| `останови таймер`, `мои напоминания` | управление таймером и список напоминаний |
| `будильник на 7:30`, `будильник на 7 вечера` | системный будильник |
| `напомни через 20 минут выпить воды` | напоминание с уведомлением |
| `фонарик`, `выключи фонарик` | вспышка |
| `заряд` | процент батареи и «пора к розетке» при низком |
| `громче`, `тише`, `без звука` | громкость музыки |
| `какой пароль от вайфая` | см. честный раздел ниже |
| `какие сети`, `какой у меня вайфай` | сохранённые сети, имя сети, сигнал, ip |
| `настройки вайфая`, `настройки приложений` | нужная страница настроек |

### Интернет и память

- `погода`, `погода в казани` — open-meteo, без ключей, помнит город.
- `что такое квантовая физика`, `расскажи о чёрных дырах` — короткий ответ
  из Википедии прямо в чат, без перехода в браузер.
- `найди рецепт борща` — если нужен список ссылок, откроет поиск.
- `меня зовут ...`, `я живу в ...`, `я люблю ...` — память о человеке.
- `что ты обо мне помнишь`, `забудь обо мне` — показать/стереть память.
- `запиши купить хлеб`, `мои заметки`, `удали заметку 1` — заметки.
- `научись: вруби ютуб = открой ютуб` — новые формулировки.
- `что ты не знаешь` — фразы, которые не поняла.

### Забота и напоминания

- `напомни через час выпить воды`, `можешь напомнить в 7 вечера о зарядке`,
  `напомни завтра в 9:00 позвонить маме` — напоминание с уведомлением.
- Nika сама иногда спрашивает «ты поел?», «попей воды», «как ты?», «пора спать»
  и присылает это уведомлением. На ответ («поел» / «нет» / «устал») она отвечает
  по теме, а не «ок»: уточнит, что ел, предложит напоминание, поддержит.
- `отключи заботу` / `включи заботу` — выключить или вернуть такие сообщения.

### Она и её вид

- `как ты выглядишь`, `покажи себя` — отдельный экран: девушка в юбке, собранная
  из линий в 1 пиксель. Линии «выстраиваются» на глазах, потом мерцают.
- `голос выше` / `голос ниже`, `говори быстрее` / `медленнее`,
  `верни обычный голос` — подстройка женского голоса под слух.

### Разговор

`привет`, `как дела`, `поговори со мной`, `мне грустно`, `я устал`, `пошути`,
`расскажи факт`, `дай совет`, `поддержи меня`, `спасибо`, `пока`…

Она помнит имя и город, замечает, сколько тебя не было, говорит «доброе утро» и
«пора спать», мягко поправляет, если перепутать её имя, выбирает слова без
повторов и сама иногда пишет первой, если долго молчишь.

## Голос

- **Говорит вслух** системным TTS (русский), кнопка «голос/тихо» в шапке.
  Голос выбирается женский: по именам и признакам голосов Android, с запасным
  вариантом по тону, если женского русского голоса в системе нет.
- **Слушает** кнопкой «мик.»: системное распознавание речи (`SpeechRecognizer`),
  над строкой ввода появляются «волны» — каждая палка шириной в 1 пиксель,
  высота зависит от громкости голоса.
- **Клавиатура** поджимает окно (`adjustResize`), поэтому поле ввода остаётся
  над ней.

## Wi-fi: как есть на самом деле

Android с версии 9 **не отдаёт приложениям пароли сохранённых сетей** — это
защита системы, без root пароль не достать никаким приложением.

- имя текущей сети, сигнал и ip — показывает всегда (нужны разрешения на геолокацию);
- список сохранённых сетей — показывает, пока система разрешает (`getConfiguredNetworks`);
- пароль — **только при root**: читает `WifiConfigStore.xml` / `wpa_supplicant.conf`
  (разбор покрыт тестами);
- без root — честно объясняет и подсказывает: настройки → wi-fi → сеть →
  «Поделиться» (QR с паролем), наклейка на роутере, кнопка WPS.

Включать/выключать wi-fi приложениям Android запрещает — Nika открывает
нужный переключатель в настройках.

## Сборка APK на GitHub (рекомендуется)

1. Положить папку в репозиторий GitHub.
2. Вкладка **Actions** → **Build Nika APK (BeeWare)** → **Run workflow**.
3. Через ~20–30 минут в **Artifacts** появится `nika-apk` (debug APK),
   его можно сразу ставить на телефон.

Что делает воркфлоу (`.github/workflows/android.yml`):
- сначала гоняет **177 тестов** логики (быстро, без Android);
- ставит Java 17 и `briefcase`, кеширует `~/.cache/briefcase`, Gradle и pip;
- `briefcase create android` (скачивает SDK/NDK) → `briefcase build android`;
- складывает все найденные `*.apk` в артефакт.

Кеш ускоряет повторные сборки: SDK/NDK и Gradle-зависимости не качаются заново.

### Локальная сборка (Linux / WSL2 / macOS)

```bash
python3 -m pip install briefcase
briefcase create android
briefcase build android
briefcase run android          # если подключён телефон с adb
# apk: build/nika/android/gradle/app/build/outputs/apk/debug/app-debug.apk
```

Нужен JDK 17 и ~15 ГБ места. Briefcase сам скачивает Android SDK/NDK.

## Запуск на компьютере

```bash
py -3.12 -m venv .venv
.venv\Scripts\pip install -r requirements-desktop.txt
.venv\Scripts\python main.py
```

Или дважды щёлкнуть `run_pc.bat`. На ПК работает чат, погода, таймеры,
напоминания, заметки, wi-fi через `netsh`, ссылки в браузере; звонки и приложения
честно отвечают «это на телефоне». Нужен Python 3.10–3.12.

Альтернатива: `briefcase dev` — сам поставит зависимости и запустит Toga.

## Тесты

```bash
python tests/run_all.py
```

177 проверок: числа словами («двадцать пять минут»), время («в 7 вечера»),
телефоны, опечатки; звонки и падежи контактов; приложения/сайты/Play Market;
таймер, будильник, напоминания (включая «можешь напомнить …», «завтра в 9»);
wi-fi (включая разбор XML и `wpa_supplicant.conf`); погода на подменённом HTTP;
память, заметки, самообучение; живой разговор; забота и ответы на «поел?»;
ответы из Википедии на подменённом HTTP; портрет из линий; фразовый прогон без
падений обработчиков; смоук Toga-интерфейса на заглушке (сборка окна, шапка без
«рядом», отправка, таймер, кнопки, экран «как ты выглядишь»).
Тесты не требуют Toga и Android — работает фейковый мост.

## Как устроено

```
pyproject.toml          конфигурация Briefcase (пакет, права Android, иконка)
main.py                 запуск на ПК (Toga)
resources/              icon-square/round/adaptive-*.png — свой логотип вместо пчелы
nika/
  app.py                интерфейс Toga: лента, кнопки, таймер, голос, портрет
  __main__.py           точка входа для Briefcase (python -m nika)
  engine.py             мозг: понимает фразу, решает, что делать
  persona.py            характер: темы, шутки, сочувствие, факты
  care.py               «ты поел?», «как ты?» и ответы на них
  knowledge.py          короткие ответы из Википедии
  look.py               портрет девушки из линий в 1 пиксель
  nlp.py                числа словами, время, телефоны, опечатки
  catalog.py            каталог приложений (пакеты) и сайтов, экстренные номера
  store.py              память в JSON (атомарная запись)
  weather.py            погода open-meteo
  wifi_parse.py         разбор wi-fi конфигов Android
  theme.py              палитра из Windows-версии
  bridge/
    base.py             общий интерфейс «телефонных» возможностей
    android.py          Chaquopy: Intent'ы, контакты, TTS/STT, wi-fi, уведомления
    desktop.py          заглушка для ПК (и netsh-вайфай на Windows)
tests/                  тесты логики + фейковый мост
tools/make_assets.ps1   иконка и заставка (старый вариант, assets/)
tools/make_icons.ps1    resources/icon-*.png для Briefcase
tools/make_preview.ps1  макет интерфейса для README
```

Логика (engine/persona/nlp) не знает про Toga и Android — поэтому проверяется
на компьютере и меняется без пересборки APK.

## Что не перенесено из Windows-версии

- **Удаление аккаунта Windows** (`Александр3 - 5866`) — Windows-специфика
  с планировщиком задач; на Android такого объекта нет.
- **YOLO-камера** (`смотри на меня`) — модель 100+ МБ и `opencv` утяжеляют APK
  в разы; вместо неё «фонарик» и системная камера.
- **Окно таймера** заменено полосой в шапке — на телефоне так удобнее.

Всё остальное — команды, память, обиды на имя, самообучение, 2-часовое
«давно не виделись», ночные реплики — на месте.

## Приватность

Всё хранится только на телефоне, в приватной папке приложения:
`nika_memory.json` (факты, заметки, напоминания, история). Никаких аккаунтов,
серверов и аналитики. Погода — единственный сетевой запрос, и только когда
ты сам просишь. Память стирается фразой «забудь обо мне».
